# 自然语言 → 挑战参数（解析规则）

本文件是 `scripts/parse-request.mjs` 的规则说明，也是语言模型手工解析时的对照表。
解析结果必须**回显给用户核对**，且只使用识别到的字段，其余走缺省值。

## 1. 参数总表

| 参数 | 取值 | 缺省 | 说明 |
|---|---|---|---|
| `--people` | 1–12 整数 | 2 | 就餐人数 |
| `--budget` | ≥0 的数字（元） | 不限 | 预算上限 |
| `--scene` | `dine-in` / `take-away` / `delivery` | `dine-in` | 就餐场景 |
| `--goal` | `balanced` / `protein` / `low-sodium` / `low-cal` / `budget` / `none` | 无 | 目标预设 |
| `--tags` | 逗号分隔标签 | 空 | 必含标签，如 `burger,side,drink` |
| `--categories` | 逗号分隔类别 | 空 | 必含类别，如 `汉堡,饮品` |
| `--must` | 餐品编码 | 空 | 必选餐品 |
| `--exclude` | 餐品编码 | 空 | 排除餐品 |
| `--max-items` | 1–20 | 不限 | 最多餐品种类数 |
| `--kcal` | ≥0 | 无 | 人均热量上限 |
| `--protein` | ≥0 | 无 | 人均蛋白质下限（g） |
| `--sodium-max` | ≥0 | 无 | 人均钠上限（mg） |
| `--coupons` / `--no-coupons` | 开关 | 优先用券 | 是否使用优惠券 |
| `--seed` | 整数 | 随机 | 复现用种子 |
| `--mode` | `auto` / `mock` / `replay` / `live` | `auto` | 数据模式 |

## 2. 关键词 → 目标预设

| 用户可能说法 | `--goal` | 展开为（人均） |
|---|---|---|
| 均衡、营养搭配、搭配、全套、完整套餐 | `balanced` | 汉堡+小食+饮品各一，500kcal / 20g 蛋白 |
| 高蛋白、蛋白、增肌、健身、长肌肉 | `protein` | 蛋白质 ≥ 30g |
| 低钠、少盐、控盐、低盐、减盐 | `low-sodium` | 钠 ≤ 900mg |
| 低卡、低热量、减肥、减脂、轻食、低脂 | `low-cal` | 热量 ≤ 450kcal |
| 省钱、便宜、划算、最省、经济、实惠 | `budget` | 不设营养目标，优先用券压低总价 |

> 目标预设与显式营养参数**可叠加**：预设提供基础值，显式 `--kcal/--protein/--sodium-max` 覆盖同名字段。

## 3. 人数识别

- 阿拉伯数字：`3人`、`3 位`、`3个人`、`3人份`
- 中文数字：`双人`、`两人`、`三人`、`十人`
- 超出 1–12 范围时忽略并在 `notes` 中提示。

## 4. 预算识别（按优先级）

1. `预算 60`、`预算¥60`
2. `¥60`、`￥60`
3. `60元`、`60块`、`60块钱`
4. `不超过 60`、`最多 60`、`控制在 60`、`60 以内`、`60 以下`

## 5. 场景识别

| 说法 | `--scene` |
|---|---|
| 堂食、店里、店内、现场吃、坐着吃 | `dine-in` |
| 外带、带走、打包、外取 | `take-away` |
| 外送、外卖、送到、配送、送餐 | `delivery` |

## 6. 歧义与边界

| 情况 | 处理方式 |
|---|---|
| 只说「便宜点」未给预算 | 用 `--goal budget`（优先用券），并说明未设预算上限 |
| 只说「随便点」 | 不传任何约束 → 由 `RuleEngine` 按种子生成随机可复现任务卡 |
| 人数缺失 | 缺省 2 人，并在回复中说明 |
| 人数与预算明显冲突（如 8 人 10 元） | 正常执行；裁判会判定无有效解并解释原因 |
| 同时出现多个目标关键词 | 按上表顺序取**第一个命中**，并在 `notes` 中说明 |
| 提到具体餐品名但无编码 | 不猜测编码；提示用户可用 `--must <编码>` 指定，或直接以目标预设执行 |

## 7. 解析器调用

```bash
# 人类可读
node skill/mc-arena/scripts/parse-request.mjs "3个人 预算60 要低卡 外带"

# 机器可读（含 args / fields / notes）
node skill/mc-arena/scripts/parse-request.mjs "双人堂食 50元以内 高蛋白 用券" --json

# 只输出参数（便于拼接命令）
node skill/mc-arena/scripts/parse-request.mjs "2人 预算30" --print-args
```
